# CORE DESIGN & ENGINEERING PRINCIPLES

These non-negotiable rules govern this entire portfolio and all related projects.
NEVER VIOLATE ANY OF THE FOLLOWING:

## 1. Visual & Aesthetic Standards (Zero AI Clichés)
- **NO PURPLE GRADIENTS**: Never use purple, violet, indigo-to-magenta, or neon purple gradients. Use sharp, high-contrast engineering colors: crisp tech-cyan (`#38bdf8`, `#0284c7`), cobalt/electric blue (`#2563eb`), emerald (`#10b981`), amber (`#f59e0b`), slate, and deep dark neutrals.
- **NO PILL-SHAPED ("WILL-SHAPED") BUTTONS**: Buttons must have professional, clean corner radii (6px - 8px), never rounded pill-capsule (9999px) shapes.
- **NO EMOJI ICONS**: Never use emojis (e.g. 🚀, ⚡, 🤖, 📄, 🧠, 🛠️) as icons in UI. Always use precise, crisp SVG vector icons or clean typography.
- **NO OVER-THE-TOP SCROLL ANIMATIONS**: Scroll reveals and transitions must be subtle, fast, crisp (0.2s - 0.25s), and natural. Never use multi-second floaty, bouncy, or jarring 3D flip effects.
- **NO CUSTOM CURSOR ANIMATION**: Never inject cursor dot followers, trailing particles, or laggy custom cursor wrappers.

## 2. Content & Copy Authenticity
- **NO FAKE REVIEWS / TESTIMONIALS**: Never fabricate customer reviews, client logos, or testimonials.
- **NO FAKE METRICS**: Never use fake numbers (e.g., "500+ happy clients", "99.9% uptime for enterprise"). Only state verified, factual academic and project milestones (e.g. "B.Tech ECE at LIET Greater Noida", "Finalist at HackIndia 2026 AI Track").
- **NO FAKE HERO TEXT OR AI-SLOUGH COPY**: No hyperbolic AI buzzword soup ("revolutionary synergistic paradigms", "passionate 10x rockstar"). Keep copy direct, clear, technical, and authentic to Abhinash Maddeshiya.
- **NO M-DASHES (EM DASHES)**: Never use em dashes (`—` or `&mdash;` or `--`). Use clean commas, parentheses, colons, or standard hyphens.
- **NO "MADE WITH AI" TAGS**: Remove any AI badges or generator branding.

## 3. Production Launch Requirements
- **CUSTOM DOMAIN**: Custom domain configuration (e.g. CNAME) must be present.
- **FAVICON**: Custom developer SVG favicon (`favicon.svg`) linked in all pages and served by the backend.
- **LEGAL COMPLIANCE PAGES**: A dedicated `privacy-policy.html` and `terms-and-conditions.html` must be created, properly styled, and linked in footers and backend routes.
- **ZERO MISTAKES**: High quality, verified, functional code at all times.
