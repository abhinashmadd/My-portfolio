# Strict Engineering & Anti-AI-Cliché Guidelines

These rules are permanent and mandatory for this repository:

1. **Never use purple gradients**: Replace all purple/violet gradients with clean electric cyan (`#38bdf8`), tech cobalt blue (`#2563eb`), emerald (`#10b981`), or clean dark slate tones.
2. **Never use pill-shaped ("will-shaped") buttons**: Buttons must be modern rectangular with subtle border-radius (6px to 8px), never 9999px pill capsules.
3. **Never use emoji icons**: Replace all emojis with crisp SVG icons.
4. **Never use over-the-top scroll animation**: All animations must be minimal, subtle, and fast (<= 0.25s).
5. **Never use custom cursor animations or particle trails**.
6. **Never use fake reviews, fake customer testimonials, or fake metrics**.
7. **Never use fake hero text or AI-slough copy**.
8. **Never use M-dashes (`—` or `&mdash;` or `--`)**: Use natural punctuation (commas, colons, hyphens, parentheses).
9. **Remove all "made with AI" tags**.
10. **Maintain production requirements**:
    - Valid SVG Favicon (`favicon.svg`) linked in all HTML heads.
    - Custom domain configuration (`CNAME`).
    - Dedicated Privacy Policy page (`privacy-policy.html`).
    - Dedicated Terms and Conditions page (`terms-and-conditions.html`).
